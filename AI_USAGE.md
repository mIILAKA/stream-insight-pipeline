# AI Assistance Disclosure

AI coding agents were used extensively for design, implementation, tests, and documentation for this portfolio project.

The repository is designed so that claims can be verified without trusting generated text:

- deterministic synthetic inputs;
- executable unit and integration tests;
- dbt data-quality assertions;
- reproducible dependency lock file;
- CI that runs the same commands documented in the README.

The public sample uses synthetic inputs and includes no real livestream audio, video, comments, or account credentials. Before using this work in an application or interview, the author should review the code and be able to explain its architecture, trade-offs, tests, and limitations.
