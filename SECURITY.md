# Security Policy

## Scope

This repository processes generated synthetic data and requires no API keys, cookies, or external service credentials.

## Reporting

Do not post secrets or personal information in a public issue. If GitHub private vulnerability reporting is enabled, use it. Otherwise, open an issue containing only a minimal, non-sensitive description so a private contact method can be arranged.

## Supported version

Only the latest commit on the default branch is supported during portfolio development.
